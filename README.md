# 💰 Expense Tracker (Python)

A lightweight, terminal-based Expense Tracker built as my very first step into Python programming, software development, and automation. This project focuses on clean logic and functional terminal execution.

## 🚀 Features
- **Add Expenses:** Easily log your daily expenses with amounts and categories.
- **View Summaries:** Get a quick breakdown of your total spending.
- **Terminal UI:** Clean and simple command-line interface for fast interaction.

## 🛠️ Tech Stack
- **Language:** Python 3.x
- **Environment:** VS Code Terminal
